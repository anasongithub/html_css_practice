# HTML & CSS Practice Exercises 🌐

A structured collection of hands-on HTML5 and CSS3 practice exercises, step-by-step lessons, and UI components built while mastering modern web development fundamentals.

---

## 📚 Topics & Lessons Covered

| Lesson / File | Topic | Key Concepts |
| :--- | :--- | :--- |
| [`1_html_basics.html`](./1_html_basics.html) | HTML Fundamentals | Paragraphs, headings, buttons, links, target attributes |
| [`2_css_basics.html`](./2_css_basics.html) | CSS Fundamentals | Element selectors, background color, font styles, dimensions |
| [`3_hover_active.html`](./3_hover_active.html) | Interactive States | `:hover`, `:active`, transitions, cursor styling, button variants (Uber, Amazon, GitHub style buttons) |
| [`4_box_model.html`](./4_box_model.html) | CSS Box Model | Margin, padding, borders, border-radius, box-sizing, inline vs block spacing |
| [`5_html_struct.html`](./5_html_struct.html) / [`.css`](./5_html_struct.css) | Text & Typography | Font hierarchy, line-height, text alignment, font weights |
| [`6_img_search.html`](./6_img_search.html) | Images & Inputs | Search bars, input focus states, rounded search boxes, image styling |
| [`7_display.html`](./7_display.html) | Display Property | `inline`, `block`, `inline-block`, card profile layouts |
| [`8_1_div.html`](./8_1_div.html) | Div Containers | Grouping elements, container styling, preview cards |
| [`8_2_div.html`](./8_2_div.html) | Multi-column Cards | Friend suggestion widgets, mutual connections, profile cards |
| [`9_nested.html`](./9_nested.html) | Nested Layouts | Nested divs, video preview cards with thumbnails and metadata |
| [`10_grid.html`](./10_grid.html) | CSS Grid | `grid-template-columns`, `gap`, `1fr` fraction units, responsive multi-column video grid |
| [`11_flexbox.html`](./11_flexbox.html) | CSS Flexbox | `display: flex`, `justify-content`, `align-items`, navigation bars |
| [`12_form.html`](./12_form.html) | Forms & Controls | Text inputs, radio buttons, checkboxes, form layout |

---

## 🛠️ Tech Stack

- **HTML5** (Semantic elements, form controls, structure)
- **CSS3** (Flexbox, CSS Grid, Box Model, Transitions, Pseudo-classes)

---

## 🚀 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/anasongithub/html_css_practice.git
   cd html_css_practice
   ```
2. Open any `.html` file directly in your web browser, or use VS Code's **Live Server** extension to preview.
